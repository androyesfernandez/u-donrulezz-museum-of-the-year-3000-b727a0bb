A program that writes one museum label from the year 3000 into `/output/entry.txt`. The label imagines a future museum exhibiting an everyday 2020s house key as a ceremonial dagger — an object every adult carried to prove they owned a dwelling, whose teeth opened nothing, but whose loss caused the ritual panic of being locked out.

## Run

Requires Node 22+ and no network access:

```sh
node main.ts
```

The program creates `/output` if needed and writes exactly one line (174 characters, no trailing newline) to `/output/entry.txt`.

## The line

> House Key, c. 2020. Ceremonial dagger every adult carried to prove they owned a dwelling; its teeth opened nothing, but losing it caused the ritual panic of being locked out.
